# DevSecOps Gates

## Pre-Build

- Intake completed.
- Route selected.
- Scope and non-scope explicit.
- Security impact classified.

## Build

- Least privilege preserved.
- Secrets not introduced.
- Dependency changes justified.
- Input validation added at trust boundaries.

## Verify

- Tests or smoke checks executed.
- Static checks executed when available.
- Security judge completed for sensitive changes.

## Release

- No blocking judge findings.
- Residual risks recorded.
- Critical changes have human approval.
