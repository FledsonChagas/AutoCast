# Security Standards Crosswalk

This crosswalk maps AutoCast security assurance concepts to common standards.

| AutoCast Concept | OWASP | NIST SSDF | CIS Controls | DevSecOps |
|---|---|---|---|---|
| Security intake | Insecure design prevention | PO/PW planning | Application software security | Shift-left classification |
| Trust boundary review | Access control, SSRF, injection | PW secure design | Access control management | Threat modeling |
| Dependency review | Vulnerable components | PS protect software | Malware defenses, inventory | Supply-chain scanning |
| Security judge | Verification and review | RV vulnerability response | Application software security | Security gates |
| Evidence log | Logging/monitoring | RV evidence and response | Audit log management | Release evidence |
| Critical approval | Insecure design prevention | PO governance | Access control and change mgmt | Human approval gate |

## Usage

Use this crosswalk to explain why a security gate exists. Do not treat it as legal compliance advice.
