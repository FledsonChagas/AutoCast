# Crosswalk De Standards De Segurança

Este crosswalk mapeia conceitos de security assurance do AutoCast para standards comuns.

| Conceito AutoCast | OWASP | NIST SSDF | CIS Controls | DevSecOps |
|---|---|---|---|---|
| Intake de segurança | Prevenção de design inseguro | Planejamento PO/PW | Segurança de software aplicativo | Classificação shift-left |
| Revisão de trust boundary | Access control, SSRF, injection | Design seguro PW | Gestão de access control | Threat modeling |
| Revisão de dependências | Vulnerable components | PS protect software | Malware defenses, inventory | Supply-chain scanning |
| Juiz de segurança | Verificação e revisão | RV vulnerability response | Segurança de software aplicativo | Security gates |
| Evidence log | Logging/monitoring | Evidência e resposta RV | Audit log management | Evidência de release |
| Aprovação crítica | Prevenção de design inseguro | Governança PO | Access control e change mgmt | Gate de aprovação humana |

## Uso

Use este crosswalk para explicar por que um gate de segurança existe. Não trate como aconselhamento legal de compliance.
