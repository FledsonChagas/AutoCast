# OpenCode Command: AutoCast

Use this as the body of an OpenCode custom command if desired.

```md
Start AutoCast for the user's request.

1. Use the AutoCast orchestrator prompt.
2. Ask only blocking intake questions.
3. Produce a task brief.
4. Select route and risk level.
5. If implementation is allowed, use builder flow.
6. Run required judges.
7. Apply security baseline and report evidence.
```

To wire this into `opencode.json`, validate against `https://opencode.ai/config.json` and restart OpenCode after saving config changes.
