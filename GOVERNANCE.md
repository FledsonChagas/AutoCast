# AutoCast Governance

AutoCast is currently maintainer-led.

## Maintainer Role

The maintainer is responsible for:

- release approval
- framework direction
- security posture
- adapter scope
- claim discipline
- accepting or rejecting contributions

## Decision Principles

- Framework standard first, optional tooling second.
- Official adapters are OpenCode, Claude Code, and Cursor.
- Security is secure by default.
- Claims require evidence.
- Samples are not proof.
- Public quality claims require pilots, benchmarks, or independent review.

## Change Classes

| Change | Required Review |
|---|---|
| Docs typo | maintainer review |
| Core spec change | maintainer review + rationale |
| Security profile change | security review |
| Adapter behavior change | adapter conformance review |
| Eval scoring change | benchmark rationale |
| Public claim change | evidence review |

## Current Governance Level

```txt
maintainer-led, pre-community
```

This is appropriate before broader external adoption exists.
