# AutoCast v1.0 Readiness

AutoCast should not become v1.0 just because the docs are large.

v1.0 should mean the framework standard is stable enough for external adoption.

## v1.0 Readiness Criteria

- Core specification is stable.
- Conformance levels are clear.
- Official adapters are documented and usable.
- Security profiles are accepted as the default model.
- Claims policy is followed.
- At least one real pilot exists, or the release is explicitly labeled pre-adoption.
- Known limitations are documented.
- Contribution and governance docs exist.

## Current Status

AutoCast v0.9 candidate is close to public-readiness, but not necessarily v1.0-ready.

The remaining gap is real adoption evidence.
