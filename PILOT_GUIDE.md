# AutoCast Pilot Guide

Use this guide to run a small AutoCast adoption pilot.

## Pilot Goal

Measure whether AutoCast improves AI-assisted development quality for a real workflow.

## Recommended Pilot Size

- 2 to 4 weeks
- 1 to 3 developers
- 10 to 30 tasks
- mix of low-risk, standard, secure, and critical tasks

## Setup

1. Choose official adapter: OpenCode, Claude Code, or Cursor.
2. Choose default profile: `standard` recommended.
3. Define when to escalate to `secure` and `critical`.
4. Record task briefs and evidence.
5. Track judge findings.
6. Review adoption friction weekly.

## Output

At the end of the pilot, produce:

- task count by route
- route accuracy estimate
- security escalation misses
- over-scope findings
- evidence completeness score
- examples of useful judge findings
- examples of unnecessary friction
- recommendation: adopt, adapt, or stop

## Anti-Bias Rules

- Include failures.
- Include tasks where AutoCast was too heavy.
- Do not score only successful tasks.
- Keep raw notes when possible.
