# AutoCast Manifesto

AutoCast is not the only right way to build software with AI.

It is one right way.

We believe AI-assisted development works better when it is:

- scoped before it is executed
- routed by risk
- secure by default
- reviewed by independent judges
- verified by evidence
- adapted to the tools developers actually use

We do not believe every task needs heavy process.

We do believe every task needs enough process for its risk.

The goal is not to slow developers down.

The goal is to make the safe path the fast path.
