# AutoCast Principles

## 1. Harness Over Prompt

Prompts are not enough. A reliable AI workflow needs prompts, scope, rubrics, judges, tests, and evidence.

## 2. Small Scope Wins

Prefer the smallest correct change. Large ambiguous tasks must be decomposed before implementation.

## 3. Judges Do Not Build

Builders implement. Judges evaluate. Mixing both roles reduces reliability.

## 4. Security Is Default

Every change is security-relevant until proven otherwise.

## 5. Evidence Beats Confidence

Do not rely on model confidence. Prefer tests, diffs, logs, static checks, threat models, and explicit acceptance criteria.

## 6. Route By Risk

The same harness should not treat typo fixes and authentication changes equally.

## 7. Ask Less, Ask Better

Ask the fewest questions needed to safely choose a workflow.
