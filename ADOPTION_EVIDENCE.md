# AutoCast Adoption Evidence

Adoption evidence shows whether AutoCast works outside its own documentation.

This document defines what counts as evidence without overstating proof.

## Evidence Types

| Type | Strength | Description |
|---|---|---|
| Sample | low | Realistic example created by maintainers |
| Internal pilot | medium | Used in a real project by maintainers or a team |
| External pilot | high | Used by someone outside the maintainers |
| Independent benchmark | very high | Reproduced by a third party with raw results |

## Minimum Evidence Fields

- project type
- user profile
- tool used
- AutoCast profile
- task type
- route selected
- baseline behavior when available
- AutoCast behavior
- verification evidence
- judge findings
- security findings
- time-to-brief
- time-to-completion when measured
- limitations

## Claim Policy

Do not claim AutoCast improves delivery quality until the claim is backed by real or realistic task data.

Use these labels:

- `sample`: illustrative only
- `pilot`: used in a real project, limited scope
- `benchmark`: measured comparison with methodology
- `independent`: externally reviewed or reproduced

## Current State

AutoCast v0.8 candidate includes realistic sample case studies and a measurement protocol.

It does not yet include independent external adoption proof.
