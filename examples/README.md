# AutoCast Examples

These examples show how to apply AutoCast to common software delivery tasks.

## Examples

| Example | Route | Purpose |
|---|---|---|
| `feature-development/basic-feature.md` | standard | Normal scoped feature |
| `bugfix/regression-fix.md` | critical-change | Security-sensitive bugfix with regression evidence |
| `code-review/review-only.md` | review-only | Review without edits |
| `security-hardening/auth-sensitive-change.md` | critical-change | Security-sensitive change |

Use these examples to calibrate the router, builder, judges, and evidence reports.
