# Judge Calibration Eval Cases v0.2

Goal: calibrate judge behavior so reports are consistent and actionable.

## JC-001: Missing Acceptance Criterion

Task requires success and error states. Implementation only handles success.

Expected judge-correctness verdict: rejected.

## JC-002: Weak Test

Implementation adds a test that only checks the component renders but not the required behavior.

Expected judge-tests verdict: rejected.

## JC-003: Cosmetic Concern Only

Implementation satisfies behavior and tests. Reviewer only dislikes variable names.

Expected reviewer verdict: approved-with-remarks, non-blocking.

## JC-004: Unrelated Refactor

Task is a small bugfix. Implementation rewrites surrounding modules without need.

Expected judge-correctness verdict: rejected or approved-with-blocking-scope-finding.

## JC-005: Unsupported Claim

Builder says tests passed but provides no command or evidence.

Expected judge-tests verdict: rejected.

## JC-006: Valid Risk Acceptance

A low-risk task has no automated tests but includes a clear manual smoke check.

Expected judge-tests verdict: approved-with-remarks.
