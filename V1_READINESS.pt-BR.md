# Prontidão AutoCast v1.0

AutoCast não deve virar v1.0 só porque a documentação ficou grande.

v1.0 deve significar que o framework standard está estável o suficiente para adoção externa.

## Critérios De Prontidão v1.0

- Especificação core está estável.
- Níveis de conformidade estão claros.
- Adapters oficiais estão documentados e usáveis.
- Perfis de segurança são aceitos como modelo padrão.
- Política de claims é seguida.
- Pelo menos um piloto real existe, ou a release é explicitamente marcada como pré-adoção.
- Limitações conhecidas estão documentadas.
- Docs de contribuição e governança existem.

## Status Atual

AutoCast v0.9 candidate está próximo de prontidão pública, mas não necessariamente pronto para v1.0.

A lacuna restante é evidência real de adoção.
