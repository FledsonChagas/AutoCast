# Governança AutoCast

AutoCast atualmente é liderado por maintainer.

## Papel Do Maintainer

O maintainer é responsável por:

- aprovação de releases
- direção do framework
- postura de segurança
- escopo dos adapters
- disciplina de claims
- aceitar ou rejeitar contribuições

## Princípios De Decisão

- Framework standard primeiro, tooling opcional depois.
- Adapters oficiais são OpenCode, Claude Code e Cursor.
- Segurança é secure by default.
- Claims exigem evidência.
- Samples não são prova.
- Claims públicos de qualidade exigem pilotos, benchmarks ou revisão independente.

## Classes De Mudança

| Mudança | Revisão Exigida |
|---|---|
| Typo em docs | revisão do maintainer |
| Mudança em spec core | revisão do maintainer + racional |
| Mudança em perfil de segurança | revisão de segurança |
| Mudança em comportamento de adapter | revisão de conformidade do adapter |
| Mudança em scoring de eval | racional de benchmark |
| Mudança em claim público | revisão de evidência |

## Nível Atual De Governança

```txt
liderado por maintainer, pré-comunidade
```

Isso é apropriado antes de adoção externa mais ampla.
