# Workflow: Code Review

## Route

Use `review-only`.

## Steps

1. Identify the diff or files to review.
2. Identify the intended behavior.
3. Reviewer lists findings ordered by severity.
4. Judge-security reviews if sensitive.
5. Output blockers, non-blockers, and residual risk.

## Review Standard

Findings first. Focus on bugs, regressions, security, and missing tests.
