# Workflow: Test Generation

## Route

Use `standard` or `secure-change` when testing security behavior.

## Steps

1. Define behavior under test.
2. Identify existing test style and framework.
3. Select test level: unit, integration, e2e, smoke, property, or regression.
4. Add the smallest useful tests.
5. Run the relevant test command.
6. Judge test quality.
7. Record coverage gaps.
